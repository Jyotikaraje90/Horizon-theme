# Homepage Design Fidelity Testing Guide
## Puerto Ink Shopify Theme

**How to use this guide:**
1. Open the Figma PDF side-by-side with the live store: https://artistic-look-store.myshopify.com
2. Test at three breakpoints: Desktop (1920px), Tablet (768px), Mobile (375px)
3. Use browser DevTools (F12) to inspect and measure elements
4. Check off each item as you verify it matches the design
5. Document any discrepancies found

---

## SECTION 1: HEADER & NAVIGATION

### Logo
- [ ] Logo displays correctly at top-left
- [ ] Logo size matches design (compare pixel dimensions)
- [ ] Logo aspect ratio is correct (not stretched/squished)
- [ ] Logo margin/padding from header edge matches design
- [ ] Logo links to homepage when clicked

### Main Navigation Menu (Desktop)
- [ ] Menu items: HOME, ABOUT US, SERVICES, SHOP JEWELRY, RESOURCES
- [ ] Font family matches design
- [ ] Font size matches design (measure with DevTools)
- [ ] Font weight matches design (regular, semi-bold, bold?)
- [ ] Font color matches design (use DevTools color picker)
- [ ] Text color is correct (not too dark/light)
- [ ] Spacing between menu items matches design
- [ ] Menu items are horizontally aligned
- [ ] Active menu item has correct styling/highlight
- [ ] Hover state works (text color change, underline, highlight?)
- [ ] Hover color matches design

### Mobile Menu
- [ ] Hamburger menu icon displays on mobile (< 768px)
- [ ] Icon size and color match design
- [ ] Icon is right-aligned
- [ ] Clicking menu opens slide-out
- [ ] Menu backdrop/overlay appears (if designed)
- [ ] Menu items stack vertically
- [ ] Menu font size is readable on mobile
- [ ] Close button/X icon is visible
- [ ] Menu closes when clicking backdrop

### Header Secondary Elements
- [ ] Search icon displays
- [ ] Search icon color matches design
- [ ] Currency/Region selector displays
- [ ] Currency selector styling matches design
- [ ] Cart icon displays
- [ ] Cart count badge displays (if items in cart)
- [ ] Account/Login link displays
- [ ] Account link styling matches design

### Header Background & Spacing
- [ ] Header background color matches design
- [ ] Header has correct height/padding
- [ ] Header spacing (top/bottom padding) matches design
- [ ] Header remains fixed to top when scrolling (if designed that way)
- [ ] Header doesn't overlap page content
